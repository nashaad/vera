# Context (experimental)

Disabled-by-default client extension. Occupancy is `/context` and
`/context all`. `/context deep` is experimental: pressure (standing rules vs
leftover text) and semantic density (SDE) for the instruction files this
workspace would inject this session.

Enable by path in the profile `extensions` list:

```json
{
  "path": "/absolute/path/to/vera/examples/extensions/context",
  "enabled": true
}
```

It is not bundled. `/context deep` calls `vera.oneshot` for the judge; pile
bytes and crude counts fill without a model.
