# vera

A durable, open agent runtime you can code with, script in Python, and build on.

Vera is under heavy development. Try the code, just expect things to move.

## Install

From the checkout:

```sh
bun install
bun run install:local
```

Then run `vera` in your project directory.

## Manual

Start with [Getting started](docs/getting-started.md), or read the manual at
