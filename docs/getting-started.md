# Getting started

Vera currently runs from a source checkout.

Install dependencies:

```sh
bun install
```

Choose one provider.

## Codex subscription

No API key or Codex CLI is required.

Sign in:

```sh
bun run src/cli.ts login openai-codex
```

Complete sign-in in the browser. Vera stores credentials in
`~/.vera/auth.json` and refreshes them automatically. Do not edit this file.

Create `~/.vera/config.json`:

```json
{
  "schema_version": 1,
  "provider": "openai-codex",
  "model": "gpt-5.6-sol"
}
```

## OpenRouter

Set `OPENROUTER_API_KEY`, then create `~/.vera/config.json`:

```json
{
  "schema_version": 1,
  "provider": "openrouter",
  "model": "anthropic/claude-sonnet-4"
}
```

## Run

```sh
bun run tui
```
